Each branch of this project sequentially addresses a specific backend development task:
* 🌐 **01-express**: Setting up a basic server and working with the Express framework.
* 🗄️ **02-mongodb**: Connecting a MongoDB database for data storage.
* 🛡️ **03-validation**: Implementing data validation.
* 🔐 **04-auth**: Handling user registration, login, and authorization.
* 📧 **05-mail-and-img**: Sending emails and uploading images to the server.
